# 倒计时

按群隔离的倒计时 / 正计时。适合游戏发售、活动前瞻、开服纪念日。

当前只支持 **aiocqhttp（OneBot v11）**。

主指令是 `/倒计时`，也可以写成 `/cd` 或 `/countdown`。如果你改过 AstrBot 唤醒前缀，把下面的 `/` 换成你的前缀。

每个群的任务互相隔离。私聊也可以单独用一份（可在配置里关掉）。

---

## 命令一览

| 命令 | 作用 | 默认谁能用 |
| --- | --- | --- |
| `/倒计时 添加` | 添加倒计时 | 管理员 |
| `/倒计时 正计时` | 添加正计时 | 管理员 |
| `/倒计时 列表` | 查看本群任务 | 所有人 |
| `/倒计时 查询` | 立刻播报一次 | 所有人 |
| `/倒计时 删除` | 删除任务 | 管理员 |
| `/倒计时 改` | 改名称 / 日期 / 模板 / 开关 | 管理员 |
| `/倒计时 开关` | 停用或重新启用一条任务 | 管理员 |
| `/倒计时 时间` | 查看或设置本群每日播报时间 | 查看所有人，修改管理员 |
| `/倒计时 开启` | 打开本群每日播报 | 管理员 |
| `/倒计时 关闭` | 关闭本群每日播报 | 管理员 |
| `/倒计时 帮助` | 查看简要用法 | 所有人 |

不写子命令时，`/倒计时` 也等于帮助。

## 和 AstrBot 对话时调用

插件会注册 5 个 LLM 工具，并附带 Skill `countdown-manager`。普通聊天里说「帮我加一个终末地前瞻倒计时，8 月 21 日 19:30」，模型应自动调用工具，而不必打斜杠指令。

| 工具 | 作用 |
| --- | --- |
| `countdown_add` | 添加倒计时或正计时 |
| `countdown_list` | 列出本群任务和序号 |
| `countdown_query` | 发查询卡片，并给模型一份文字摘要 |
| `countdown_edit` | 改名称、日期、模板、开关 |
| `countdown_delete` | 按序号或名称删除 |

添加 / 修改 / 删除仍走原来的管理员权限。可在配置里关掉 `enable_llm_tools`。

Skill 装上后会出现在 WebUI 的 Skills 页。插件启动时会把同一份 `SKILL.md` 同步到 `data/skills/countdown-manager/`，方便沙盒模式扫描。人格如果改成「不使用任何 Skills」，模型可能不会按手册来调，但 `countdown_*` 工具仍会注册。

若日志里出现 `Skill sync phase=scan returned empty payload` 或去读 `/workspace/skills/countdown-manager/SKILL.md` 失败：那是沙盒工作区里没有这份文件，**不影响**直接调用 `countdown_add` 等工具。开一个新对话，让沙盒重新同步即可。

## `/倒计时 添加`

添加一条倒计时。日期写在名称后面，插件会自己认出日期，书名号后面的说明也会算进名称。

```text
/倒计时 添加 <名称> <日期或日期时间> [模板]
```

别名：`add`、`新建`

**示例**

```text
/倒计时 添加 《Dota3》 2060-01-31
/倒计时 添加 《Dota3》 2060-01-31 距离《{name}》发售还有{days}天
/倒计时 添加 《明日方舟：终末地》前瞻 2026年8月21日19:30
/倒计时 添加 "明日方舟：终末地" 2026-08-20 18:00
```

**日期怎么写**

| 写法 | 说明 |
| --- | --- |
| `2026-08-21` | 年月日 |
| `2026/8/21` | 同上 |
| `2026年8月21日` | 中文日期 |
| `8月21日` | 只有月日：倒计时落到今天或下一个未到的日期 |
| `2026-08-21 19:30` | 日期 + 时刻 |
| `2026年8月21日19:30` | 时刻可以跟在日期后面，中间没有空格也行 |

不写模板时：

- 只有日期：`距离{name}还有{days}天`
- 带了时刻：`距离{name}还有{remain}`，例如「还有 10小时30分钟」

带时刻的任务还会：

1. 正点前 10 分钟提醒：`{name}还有10分钟！`
2. 到点提醒：`{name}到时间了！`
3. 到点提醒发出后再删除

## `/倒计时 正计时`

添加一条正计时，从某个已经过去的日期往现在数。

```text
/倒计时 正计时 <名称> <起始日期> [模板]
```

别名：`up`、`countup`

**示例**

```text
/倒计时 正计时 开服 2024-06-01
/倒计时 正计时 开服 2024-06-01 {name}已经过去{days}天
```

只有月日时，会落到今天或上一个已经过去的日期。正计时不会自动删除。

---

## `/倒计时 列表`

查看本群全部任务、每日播报时间，以及每条还剩 / 已过多少。

```text
/倒计时 列表
```

别名：`list`、`ls`

序号就是后面删除、修改、开关时用的编号。

---

## `/倒计时 查询`

马上按当前模板播报一次，默认发图片卡片；出图失败则发文字。

```text
/倒计时 查询
```

别名：`播报`、`now`、`query`

这不会改「今天是否已经例行播报过」的标记，也不会因此删除任务。

---

## `/倒计时 删除`

按列表序号或名称删除本群一条任务。

```text
/倒计时 删除 <序号或名称>
```

别名：`del`、`delete`、`rm`

**示例**

```text
/倒计时 删除 1
/倒计时 删除 Dota3
/倒计时 删除 《明日方舟：终末地》前瞻
```

---

## `/倒计时 改`

改已有任务的名称、日期、模板或启用状态。

```text
/倒计时 改 <序号或名称> <字段> <新值>
```

别名：`编辑`、`edit`

| 字段 | 也可以写成 | 新值 |
| --- | --- | --- |
| `名称` | `名字`、`name` | 新名称 |
| `日期` | `时间`、`date` | 新的日期或日期时间 |
| `模板` | `句式`、`template` | 新的句式模板 |
| `开关` | `enabled` | `开` / `关` |

**示例**

```text
/倒计时 改 1 名称 《Dota3》发售
/倒计时 改 1 日期 2026-12-31 18:00
/倒计时 改 1 模板 距离{name}还有{remain}
/倒计时 改 1 开关 关
```

改日期后，正点前提醒和到点提醒的标记会清掉，到时候会再发。

---

## `/倒计时 开关`

停用或重新启用一条任务。停用后不参与每日播报和到点提醒，但还留在列表里。

```text
/倒计时 开关 <序号或名称>
```

别名：`toggle`

```text
/倒计时 开关 1
```

---

## `/倒计时 时间`

查看或设置**本群**的每日播报时间。不改其他群，也不改仪表盘里的全局默认。

```text
/倒计时 时间
/倒计时 时间 21:30
/倒计时 时间 默认
```

别名：`time`

- 不带参数：查看当前时间，以及它来自本群自定义还是插件默认
- `HH:MM`：设为本群时间
- `默认` / `default` / `reset`：改回插件配置里的默认时间

全局默认在 WebUI 插件配置的「默认定时播报时间」，出厂是 `09:00`。

---

## `/倒计时 开启` / `/倒计时 关闭`

打开或关闭本群的每日定时播报。关掉后任务还在，仍可用 `/倒计时 查询` 手动看。

```text
/倒计时 开启
/倒计时 关闭
```

别名：`enable` / `on`，`disable` / `off`

---

## `/倒计时 帮助`

```text
/倒计时
/倒计时 帮助
```

别名：`help`、`?`

## 播报长什么样

每天到点后，群里会发一张卡片，内容等价于：

```text
今天是2060年1月1日。
- 距离《Dota3》发售还有30天
- 距离《明日方舟：终末地》前瞻还有10小时30分钟
```

只写日期的任务，到当天会改成 `{name}就在今天！`，播报后删除。  
带时刻的任务，当天早上仍按剩余时间播报；正点前提醒一次，到点再提醒一次，然后删除。

## 模板占位符

添加或修改任务时可以自己写句式。没写的占位符会原样留在句子里，不会报错。

**标题**（仪表盘里配，每天播报最上面那一行）

| 占位符 | 含义 | 例子 |
| --- | --- | --- |
| `{today}` | 今天 | 2060年1月1日 |
| `{today_iso}` | 今天（ISO） | 2060-01-01 |
| `{year}` `{month}` `{day}` | 年 / 月 / 日，不补零 | 2060 / 1 / 1 |
| `{month_02}` `{day_02}` | 补零的月 / 日 | 01 / 01 |
| `{weekday}` | 星期 | 星期一 |
| `{weekday_short}` | 周几 | 周一 |
| `{hour}` `{minute}` | 当前时 / 分 | 9 / 0 |

**任务条目**

| 占位符 | 含义 | 例子 |
| --- | --- | --- |
| `{name}` | 任务名称 | 《Dota3》 |
| `{days}` | 剩余整天数 | 30 |
| `{hours}` | 去掉整天后的小时 | 10 |
| `{minutes}` | 去掉小时后的分钟 | 30 |
| `{remain}` | 拼好的剩余时间 | 2天3小时、10小时30分钟 |
| `{target}` | 目标日期；带时刻时含时间 | 2026年8月21日 19:30 |
| `{target_time}` | 目标时刻 | 19:30 |
| `{mode}` | 倒计时 或 正计时 | 倒计时 |

## 权限

默认只有 **AstrBot 仪表盘管理员** 能添加、删除、修改。

1. 群里发 `/sid`，记下 `UID`
2. WebUI：`配置 -> 其他配置 -> 管理员 ID`
3. 把 UID 加进去

也可以在本插件配置里改 `manage_permission`：

| 值 | 谁能管理任务 |
| --- | --- |
| `astrbot_admin` | 仅仪表盘管理员（默认） |
| `plugin_admin` | 下面填写的 QQ 号；仪表盘管理员始终可以 |
| `group_admin` | 该 QQ 群的群主 / 管理员 |
| `all` | 所有人 |

`allow_query_all` 默认开着，普通成员可以用列表和查询。

## 配置和数据

安装后到 WebUI 插件页改：

- 时区、默认定时播报时间
- 标题模板、仅日期 / 带时刻 / 正计时默认模板、到期当天模板
- 正点前提醒分钟数和模板、到点提醒模板
- 是否发图片卡片
- 权限模式、额外管理员
- 到期是否清理、错过播报的补发窗口、每群任务上限
- 到期当天是否 `@全体成员`（默认关）

任务存在 `data/plugin_data/astrbot_plugin_countdown/data.json`，更新插件不会丢。

## 安装

1. 插件市场安装，或把本仓库放到 `data/plugins/astrbot_plugin_countdown`
2. 重启或在插件页重载
3. 在仪表盘加上管理员，按需改默认模板和播报时间

从文件安装时，先在仓库根目录打包：

```bash
python pack.py
```

得到 `dist/astrbot_plugin_countdown-v1.4.1.zip`。请先卸载旧版再上传，不要直接覆盖。

```bash
python pack.py --include-tests
python pack.py -o D:\tmp\countdown.zip
```

开发时：

```bash
python -m pytest tests
```
